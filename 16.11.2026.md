## Задание: Консольное приложение с меню

Создать консольное приложение, в котором будет меню:

1) угадай число
2) быки и коровы  
3) рассчитай премию
4) дежурства

При выборе пункта нужно выполнить команду на экземпляре нужного класса, выполнить его назначение, после чего вернуться в меню.
Пример работы меню в конце.

---

### Общие требования:

**Создать интерфейс `IMenuItem`** со следующим контрактом:
- Метод `Execute()` - выполняет действие выбранного пункта меню
- Свойство `Title` - возвращает название пункта меню для отображения в списке

Все классы, реализующие пункты меню, должны имплементировать этот интерфейс.

---

### 1 пункт: Игра "Угадай число"

**Создать интерфейс `IGame`**, который наследует `IMenuItem`:
- Метод `Play()` - запускает игру

**Создать класс `GuessNumber`**, реализующий `IGame`:
- Назначение класса - мини-игра "угадай число"
- Компьютер загадывает случайное число от 1 до 100
- Пользователь должен его угадать
- После каждого хода программа сообщает, больше или меньше введенное число, чем загаданное
- Если пользователь угадал за 3 шага - он молодец
- Если за 5 и меньше - он хорош  
- Если за 7 и выше - ему надо тренироваться

---

### 2 пункт: Игра "Быки и коровы"

**Создать класс `BullCows`**, реализующий `IGame`:
- Компьютер загадывает четырехзначное число, состоящее из уникальных цифр
- Пользователь вводит свои предположения
- Программа отвечает количеством "быков" (цифра совпадает и стоит на правильном месте) и "коров" (цифра присутствует, но стоит на неправильном месте)

---

### 3 пункт: Расчет премии работника

**Создать интерфейс `IEmployee`**:
- Свойства: `LastName` (фамилия), `Experience` (стаж в годах), `HourlyRate` (часовая заработная плата), `WorkedHours` (количество отработанных часов)
- Метод `GetSalary()` - рассчитывает зарплату
- Метод `GetBonusPay()` - рассчитывает премию

**Создать класс `Employee`**, реализующий `IEmployee`:
- С помощью конструктора реализовать ввод данных работника с клавиатуры
- Размер премии определяется в зависимости от стажа:
  - до 1 года: 0%
  - до 3 лет: 5%
  - до 5 лет: 8%
  - свыше 5 лет: 15%

**Создать класс `CalculateBonus`**, реализующий `IMenuItem`:
- В методе `Execute()` создает экземпляр `Employee`, запрашивает данные, вычисляет и выводит зарплату и премию

---

### 4 пункт: Система дежурств

**Создать класс `Student`**:
- Свойства: `LastName` (фамилия), `FirstName` (имя), `DutyCount` (количество дежурств)

**Создать интерфейс `IDutyManager`**, который наследует `IMenuItem`:
- Метод `GetTodayDuty()` - возвращает список из двух студентов, которые сегодня дежурят
- Метод `ApproveDuty(List<Student> students)` - принимает список из одного или двух студентов и увеличивает счетчик проведенных дежурств для каждого
- Метод `Save()` - сохраняет данные в файл

**Создать класс `StudentDuty`**, реализующий `IDutyManager`:
- Хранит список студентов
- Выбор студентов для дежурства основывается на количестве дежурств - в первую очередь дежурят те, у кого наименьшее количество проведенных дежурств
- Конструктор загружает данные из файла (если файл существует)
- При отсутствии файла создается пустой список

---

### Пример метода Main:


Вот пример вызова команды из меню с использованием интерфейсов:

```csharp
class Program
{
    static void Main(string[] args)
    {
        // Создаем список пунктов меню через интерфейс
        List<IMenuItem> menuItems = new List<IMenuItem>
        {
            new GuessNumber(),
            new BullCows(),
            new CalculateBonus(),
            new StudentDuty()
        };

        bool exit = false;

        while (!exit)
        {
            // Отображаем меню
            Console.WriteLine("\n=== Главное меню ===");
            for (int i = 0; i < menuItems.Count; i++)
            {
                Console.WriteLine($"{i + 1}) {menuItems[i].Title}");
            }
            Console.WriteLine($"{menuItems.Count + 1}) Выход");
            Console.Write("Выберите пункт: ");

            // Читаем выбор пользователя
            if (int.TryParse(Console.ReadLine(), out int choice))
            {
                if (choice >= 1 && choice <= menuItems.Count)
                {
                    // Вызываем метод Execute() через интерфейс
                    menuItems[choice - 1].Execute();
                }
                else if (choice == menuItems.Count + 1)
                {
                    exit = true;
                    Console.WriteLine("До свидания!");
                }
                else
                {
                    Console.WriteLine("Неверный выбор. Попробуйте снова.");
                }
            }
            else
            {
                Console.WriteLine("Пожалуйста, введите число.");
            }
        }
    }
}
```
