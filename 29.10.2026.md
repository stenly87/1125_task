Добавьте в класс конструктор, который требует один аргумент типа string c именем name. Конструктор должен назначить значение аргумента в свойство Name.

Добавьте в класс метод Feed типа void, c аргументом title типа string. Содержимое метода: Если Sleeping, то метод должен прерываться, в противном случае случайным образом выводим в консоль строку о том, стала ли кошка есть то, что ей дали. title - в данном случае название еды.

Добавьте в класс метод ChangeAction типа void, без аргументов. Содержимое метода: случайным образом меняется значение свойства Sleeping

В методе Main создайте объект типа Cat, после создайте циклическое меню - запрос команды. Команда feed - запускает Feed у объекта Cat, команда exit - прекращает работу, другие строки запускают случайным образом MakeNoise (30% вероятность) или ChangeAction (70% вероятность)

## 3
Создадим очень приземленный вариант автомобиля
Создайте классы: Car, Engine, Wheel и перечисление DriveType. В перечислении определите 2 значения: TwoWheelDrive и FourWheelDrive.

Класс Engine:
- Свойство логического типа IsRunning (с геттером, сеттер приватный)
- Свойство целого типа Speed (с геттером, сеттер приватный)
- Два метода: Start и Stop. Методы переключают значение свойства IsRunning и пишут в консоль состояние двигателя
- Конструктор, который принимает значение speed и сохраняет его в свойство Speed

Класс Wheel:
- Свойство целочисленного типа RotationSpeed (с геттером, сеттер приватный)
- Метод Rotate с аргументом целого типа speed (значение аргумента передается в свойство RotationSpeed)
- Метод Stop (обнуляет RotationSpeed)

Класс Car:
- поле типа Engine
- поле типа DriveType
- поле-массив типа Wheel (4 элемента)

Первый конструктор с одним аргументом типа DriveType: 
- Инициализирует поле типа Engine (создает новый двигатель со стандартной скоростью)
- Создает массив из 4 колес
- Сохраняет аргумент в поле типа DriveType

Второй конструктор с двумя аргументами (DriveType и Engine):
- Принимает готовый объект двигателя как второй аргумент
- Создает массив из 4 колес
- Сохраняет аргументы в соответствующие поля

Метод Start:
- Запускает двигатель (вызывает метод Start у Engine)
- В зависимости от значения DriveType вызывает метод Rotate на двух или четырех колесах
- Скорость колесам передает от двигателя (из свойства Speed)
- Выводит в консоль информацию о запуске автомобиля

Метод Stop:
- Выключает двигатель (вызывает метод Stop у Engine)
- Останавливает ВСЕ колеса (вызывает метод Stop у каждого колеса в массиве)
- Выводит в консоль информацию об остановке автомобиля

В классе Program, в методе Main:
- Создайте автомобили разных типов привода
- В одном авто должен быть использован первый конструктор, в другом - второй конструктор
- Попробуйте создать разные автомобили с одним общим двигателем
- Попробуйте создать один и тот же тип автомобиля с разными двигателями
- Протестируйте методы Start и Stop
