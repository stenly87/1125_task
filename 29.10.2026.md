## 1
Создайте класс Cat в новом файле
В классе добавьте свойства string Name, bool Sleeping

Добавьте в класс конструктор, который требует один аргумент типа string c именем name. Конструктор должен назначить значение аргумента в свойство Name.

Добавьте в класс метод Feed типа void, c аргументом title типа string. Содержимое метода: Если Sleeping, то метод должен прерываться, в противном случае случайным образом выводим в консоль строку о том, стала ли кошка есть то, что ей дали. title - в данном случае название еды.

Добавьте в класс метод MakeNoise типа void, без аргументов. Содержимое метода: Если Sleeping, то метод должен прерываться, в противном случае в консоль можно вывести одно из слов: "мяу", "мурр", "мурк" или что-то типа того

Добавьте в класс метод ChangeAction типа void, без аргументов. Содержимое метода: случайным образом меняется значение свойства Sleeping

В методе Main создайте объект типа Cat, после создайте циклическое меню - запрос команды. Команда feed - запускает Feed у объекта Cat, команда exit - прекращает работу, другие строки запускают случайным образом MakeNoise (30% вероятность) или ChangeAction (70% вероятность)

(Добавьте кошке еще пару методов, которые будут запускаться случайным образом через метод ChangeAction).


## 2
Создать класс Student, добавить в него свойства для хранения имени, фамилии, отчества, даты рождения(тип DateTime)
Создать класс Group, добавить в него свойства для хранения номера группы, списка студентов (тип List<Student>)
Создать класс Curator, добавить в него свойства для хранения имени, фамилии, отчества, списка групп (тип List<Group>)
Создать класс Specialty, добавить в него свойства для хранения номера, названия, списка групп (тип List<Group>)

В методе Main класса Program создать обьекты для вашей специальности, вашего куратора, вашей группы, и добавить в группу несколько студентов, вывести информацию о всех объектах на консоль
