# Немного порисуем в консоли
# Работаем в Windows. Если нет Rider, подойдет Visual Studio

## 1. Установка NuGet-пакета

- Нажмите правой кнопкой мыши по названию проекта
- Выберите **Manage NuGet Packages** или **Управление пакетами NuGet**
- В списке найдите `System.Drawing.Common`
- Выберите версию **10**
- Нажмите **+** для установки

## 2. Создание поля Graphics

В классе `Program` создайте поле типа `Graphics` с именем `paint`:

```csharp
private static Graphics paint;
```

## 3. Инициализация в методе Main

```csharp
paint = Graphics.FromHwnd(Process.GetCurrentProcess().MainWindowHandle);
// Здесь мы указываем, что объект Graphics сможет рисовать поверх окна консоли
```

## 4. Методы рисования

На объекте `paint` можно вызывать различные методы для рисования примитивов:

- **Методы, начинающиеся на `Draw`** — рисуют контур фигуры и используют объект `Pen`
- **Методы, начинающиеся на `Fill`** — создают заливку фигуры и используют объект `Brush`

## 5. Ручки (Pen) и кисти (Brush)

### Готовые объекты

- Готовые ручки находятся в статичном классе `Pens`
- Готовые кисти находятся в статичном классе `Brushes`

### Создание пользовательских объектов

Если нужны иные настройки, создавайте объекты вручную:

**Пример для ручки:**
```csharp
Pen pen = new Pen(Color.Red, 3);
```

**Пример для кисти:**
```csharp
Brush brush = new LinearGradientBrush(
    new Point(0, 0), 
    new Point(100, 100), 
    Color.Red, 
    Color.Blue
);
```

## 6. Примеры рисования фигур

```csharp
// Заливка прямоугольника
paint.FillRectangle(Brushes.Red, 10, 10, 10, 10);

// Контур прямоугольника
paint.DrawRectangle(Pens.Red, 20, 20, 50, 50);
```

## 7. Рисование сложных фигур

Некоторые сложные фигуры требуют массив точек:

```csharp
paint.FillPolygon(Brushes.Red, new Point[] {
    new Point(10, 10),
    new Point(20, 10),
    new Point(40, 40)
});
```

## 8. Система координат

- Координаты отсчитываются от **верхнего левого угла** консоли
- Точка **(0, 0)** находится в верхнем левом углу
- Чем больше значение по **X** — тем **правее** точка
- Чем больше значение по **Y** — тем **ниже** точка

## 9. Практическое задание

Теперь вы можете создавать методы, которые будут рисовать небольшие фигуры. Попробуйте создать какой-то простой рисунок с помощью таких методов.

## 10. Настройка запуска в Rider. Если работаете в Visual Studio, пропускайте

В Rider нужно настроить запуск приложения во внешней консоли:

1. Откройте конфигурацию запуска (**Run - Edit Configurations...**)
2. Найдите пункт **Terminal mode**
3. Переключите его в режим **External Console** и нажмите **Ok**

## 11. Задержка программы

Не забудьте добавить `Console.ReadLine()` в конце метода `Main`, чтобы программа остановилась и вы успели увидеть свой рисунок
